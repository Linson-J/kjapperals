GST Configuration Guide

How to configure GST and how the calculation works in this store.

1. Enable or Disable GST

Turn GST Enabled on when GST should be calculated and displayed to customers. Turn it off when GST should not appear on the customer cart, checkout, order success page, or order email.

Orders store a GST enabled snapshot. If GST was disabled when an order was placed, that order will not show GST details later.

2. Seller State Controls CGST/SGST vs IGST

Enter the business seller state, for example Tamil Nadu. During checkout, the system compares this with the customer's state.

  • If seller state and customer state are the same, tax is split into CGST and SGST.
  • If they are different, the full tax is shown as IGST.
Seller State: Tamil Nadu Customer State: Tamil Nadu GST 18% = CGST 9% + SGST 9% Seller State: Tamil Nadu Customer State: Kerala GST 18% = IGST 18%

3. Default GST Rate

The default GST rate is used when a product does not have its own GST rate and its category also does not have a GST rate.

  1. Set common rates in the GST Rates table, such as 0%, 5%, 12%, 18%, and 28%.
  2. Select the most common rate as the default rate.
  3. Use category or product GST overrides only where needed.

4. Category and Product GST Priority

The system chooses GST rate in this order:

  1. Product GST rate, if selected.
  2. Category GST rate, if selected.
  3. Default GST rate from this configuration.

Use product GST for exceptions. Use category GST when many products in a category share the same tax rate.

5. Inclusive vs Exclusive Pricing

Exclusive means GST is added on top of the product price. Inclusive means the displayed product price already contains GST.

Exclusive: Product price Rs. 1000 GST 18% = Rs. 180 Customer pays Rs. 1180 Inclusive: Display price Rs. 1000 Taxable amount Rs. 847.46 GST portion Rs. 152.54 Customer pays Rs. 1000

6. Discounts and Shipping

Coupon discounts are applied before GST. If multiple products are in the cart, the coupon discount is split across line items before tax is calculated.

Shipping is added after product GST. Current implementation does not calculate GST on shipping charges.

7. Order and Invoice Accuracy

When an order is created, the system stores the product price, taxable amount, GST percentage, CGST, SGST, IGST, HSN/SAC, and final amount on the order item.

This means old orders remain correct even if you change GST rates later.

Recommended Setup Steps

  1. Create or verify GST rates: 0%, 5%, 12%, 18%, and 28%.
  2. Enable GST.
  3. Set seller state and seller GSTIN.
  4. Select default GST rate.
  5. Set default pricing mode.
  6. Assign category GST rates for broad product groups.
  7. Assign product-specific GST and HSN/SAC only when needed.
  8. Test cart and checkout using a same-state and different-state address.
